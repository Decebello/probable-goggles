# Реализация расчета прогрессивного НДФЛ в Python

Данный пакет представляет собой программное решение для вычисления налога на доходы физических лиц (НДФЛ) согласно обновленной прогрессивной шкале, вступившей в силу в Российской Федерации в 2025 году.

## Архитектура и логика работы

В основе пакета лежит функция `calculate_tax`, которая принимает на вход годовой доход пользователя и возвращает точную сумму налога. Логика расчета базируется на пятиступенчатой системе:
* Базовая ставка **13%** применяется к доходам, не превышающим 2,4 млн рублей.
* При доходе от 2,4 до 5 млн рублей уплачивается фиксированная сумма 312 тыс. рублей плюс **15%** с суммы, превышающей базовый порог.
* Для доходов от 5 до 20 млн рублей налог составляет 702 тыс. рублей и **18%** с превышения.
* От 20 до 50 млн рублей — 3,402 млн рублей и **20%** с превышения.
* Сверхдоходы (более 50 млн рублей) облагаются фиксированной базой 9,402 млн рублей и максимальной ставкой **22%** с суммы превышения.

Важно отметить, что повышенная ставка применяется исключительно к дельте, а не к полной сумме дохода, что обеспечивает плавность налоговой нагрузки.

## Использование
```python
from ndfl.calculator import calculate_tax

# Расчёт налога при годовом доходе 200 000 руб.
tax = calculate_tax(200_000)
print(tax)  # 26000.0

# Расчёт налога при годовом доходе 3 000 000 руб.
tax = calculate_tax(3_000_000)
print(tax)  # 402000.0
```

## Последовательность действий для разработки

1. Создать виртуальное окружение: `python -m venv .venv`
2. Установить зависимости: `pip install -r requirements.txt`
3. Установить пакет в режиме разработки: `pip install -e .`
4. Проверить типы: `mypy src/`
5. Проверить стиль кода: `flake8 src/ tests/`
6. Запустить тесты: `pytest tests/`
7. Собрать пакет: `python -m build`
8. Загрузить на TestPyPI: `twine upload --repository testpypi dist/*`
