# Монорепозиторий проектов FOSSDEV

Добро пожаловать в единый репозиторий, содержащий исходные коды, документацию и конфигурации, разработанные в рамках курса FOSSDEV. Данный репозиторий спроектирован для демонстрации практических навыков автоматизации, тестирования и работы с системами контроля версий.

## Навигация по проектам

Разработка ведется в изолированных директориях, каждая из которых представляет собой независимый модуль или пакет:

1. **Модуль `testing_tdd/` (ndfl-calculator200489)**
   Это полноценный Python-пакет, реализующий калькулятор подоходного налога по актуальной прогрессивной шкале РФ. Проект демонстрирует применение Test-Driven Development (TDD), строгую типизацию, линтинг и CI/CD пайплайн с публикацией артефактов на TestPyPI.
   * *Точка входа в проект:* [Перейти к документации пакета](./testing_tdd/README.md)
   * *Установка:* `pip install --index-url https://test.pypi.org/simple/ ndfl-calculator200489`

2. **Модуль `testing/`**
   Директория содержит базовые упражнения по написанию unit-тестов и работе с моками.

3. **Модуль `bash-practice/`**
   Среда для выполнения скриптов и автоматизации задач средствами командной оболочки Bash (проект находится в стадии активной разработки).

## Организация работы

Вся работа с проектами ведется в изолированных Git-ветках. При интеграции изменений в основную ветку строго контролируется отсутствие артефактов сборки и кэша благодаря корректно настроенному файлу `.gitignore`. Каждый пакет имеет собственную автоматизацию сборки, что гарантирует воспроизводимость результатов вне зависимости от системного окружения.
